Privacy Policy

Nashville Events Pilot · Last updated: October 10, 2026

Nashville Events Pilot is a personal event-collection and calendar-management tool.

Data accessed and purpose

The tool collects public event details, including titles, dates, venues, addresses, and source links. With the owner's Google authorization, it reads calendar information and existing event details, manages collected events in a designated Google Calendar, and reads and updates a designated Google Sheet. It reads follow-up notes and visibility preferences to apply the owner's choices.

Google permissions can allow access beyond these destinations. The application is configured to use the selected calendar and spreadsheet for collection and synchronization.

Storage and service providers

Event data, follow-up notes, and synchronization history are stored on the owner's Mac and in a private GitHub repository. The designated calendar and spreadsheet are stored by Google.

For planned cloud automation, Google authorization credentials will be stored in GitHub Actions secrets and used temporarily by the automated runner. Credentials are excluded from repository uploads. Google and GitHub process data through their services under their respective policies.

Data use and sharing

The tool does not sell Google user data or use it for advertising or AI-model training. Data is processed to provide event collection and synchronization. Calendar and spreadsheet visibility depend on the owner's sharing settings.

Retention, deletion, and revocation

Records remain until the owner removes them. Stopping the tool does not automatically delete calendar events, spreadsheet rows, local files, or repository history. Full deletion may require removing those records and stored copies separately.

Access can be revoked through the Google Account's third-party connections settings. Revoking access stops future authorized requests but does not delete existing records.
