Nashville Events Pilot

A personal tool that collects publicly listed events from selected Nashville-area venues and organizes them in a designated Google Sheet and Google Calendar.

Google authorization lets the tool read calendar information, manage collected events in the designated calendar, and read and update the designated spreadsheet. It also reads follow-up notes and visibility preferences entered by the owner.

The tool is currently a three-source pilot. Daily cloud updates are being configured. Event listings may change; consult the linked event source for current details.

This website provides information about the tool. It does not display the owner's calendar, spreadsheet, notes, or credentials.
